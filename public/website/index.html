Frequently Asked Questions

Everything you need to know about AI SEO Optimizer for Shopify.

Does it work with large catalogs?
+
Yes. It uses Shopify’s Bulk Operations API and chunked saving, so it easily handles thousands of products, files, and collections without hitting rate limits or crashing.
Will AI overwrite my existing SEO?
+
You choose what to generate: only missing items, selected items, or a full regenerate. You can review, inline-edit, and verify every single field before publishing to Shopify.
Does it need coding or theme changes?
+
No coding required. It writes directly to Shopify’s native SEO fields and standard metafields, so it functions seamlessly with any Shopify theme out of the box.
Does it optimize blogs and pages too?
+
Yes! It covers all four key store resources: products, category collections, content pages (About Us, Contact, FAQ, Policies), and blog articles.
What are the title and description limits?
+
Following Google’s official search engine recommendations, SEO titles are clamped to 50 characters or fewer, and meta descriptions to 150 characters or fewer to prevent search cutoffs.
What if a Shopify permission is missing?
+
The app features self-healing permission checks. If a scope like write_content or write_files is missing, it alerts you with a 1-click re-authorization button so nothing breaks.
